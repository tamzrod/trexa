## Theme Specification

### Theme Definitions

| Theme | Trigger | Default |
|-------|---------|---------|
| Light | `prefers-color-scheme: light` or manual | Yes |
| Dark | `prefers-color-scheme: dark` or manual | Optional |
| High Contrast | `forced-colors: active` or manual | Accessibility |

### Implementation Pattern

```
User Preference → Auto (System) → Manual Override
                     ↓
              prefers-color-scheme
                     ↓
              Light or Dark
```

### Theme Requirements

| Requirement | Implementation |
|-------------|----------------|
| No flash on load | CSS-based, no JS blocking |
| Persistent preference | localStorage |
| Keyboard toggle | Ctrl+Shift+L |
| System detection | prefers-color-scheme |
| High contrast | forced-colors media query |

### Theme Switching Architecture

```css
/* Light theme (default) */
:root {
  --color-bg: #FFFFFF;
  --color-text: #111827;
}

/* Dark theme */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #111827;
    --color-text: #FFFFFF;
  }
}

/* High contrast */
@media (forced-colors: active) {
  :root {
    --color-bg: Canvas;
    --color-text: CanvasText;
  }
}
```
