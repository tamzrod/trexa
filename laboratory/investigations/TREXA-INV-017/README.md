**Problem**: No formal lifecycle exists governing how artifacts evolve, merge, archive, or are removed.

## Recommendation

**Adopt GOV-LIFECYCLE-001: KDE Knowledge Artifact Lifecycle Policy**

### Lifecycle States (8 states)

| State | Description |
|-------|-------------|
| DRAFT | Initial creation |
| ACTIVE | Approved, current |
| REVREQ | Needs revision |
| MERGED | Consolidated |
| SUPERSEDED | Replaced |
| HISTORICAL | Preserved for context |
| ARCHIVED | Not maintained |
| REMOVED | Deleted |

### Key Principles

1. **Extract Before Remove** - Knowledge over container
2. **Merge Before Delete** - Consolidate duplicates
3. **Archive Before Remove** - Preserve historical context
4. **Authorize Before Remove** - Human approval required
